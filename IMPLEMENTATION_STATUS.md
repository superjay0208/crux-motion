## Current implementation

The TypeScript/Vite/Canvas game runs both locally (`run.bat` → `http://127.0.0.1:4318/`) and statically on GitHub Pages (`https://superjay0208.github.io/crux-motion/`). It includes **twelve open-selection boulders (`B1`–`B6`, `01 Warmup Buckets` through `12 The King Line`)** unlocked directly on the landing topo grid (`?route=motion-01`..`motion-12` deep-linking), an autonomous landing-screen physics showcase, a high-margin **3-grip + Release** gesture engine (`Jug`, `Crimp`, `Pinch`, `Open` with live 4-class confidence meters and strict 1-to-1 hold matching), palm-orientation recognition (`upright`, `scoop` undercling, `sidepull`), anatomical hand association across crossed arms, local MediaPipe `paired` (`Pose + Hands`) and `holistic` providers (lazy-loaded off the landing path), personal calibration, hands-free start and auto-recenter gates, **Warm Limestone/Terracotta Bouldering Topo UI** (`Fredoka` + `Bebas Neue` + `BarlowCondensed`), **Polygon-Sculpted 2D Climber & 3D Holds**, **Dual Stamina & Forearm Pump** (diegetic *Jusant*-style climber arcs + HUD `#stamina-panel`), **Pure Match-Top Win Rule**, **Simultaneous Two-Hand Dyno + Swing/Push-Up Momentum**, **Apex Deadpoint catches**, **Impact Frames & Micro Hit-Stop**, **7-dot Ballistic Launch Arc previews**, **Assisted climb mode**, **Personal Best Ghosts**, practice **Hand anchors** + `WASD`/arrow swing + `V` simultaneous two-hand release + airborne dual-hand aim, layered procedural Web Audio, semantic replays, route demonstrations, checkpoint practice, and an opt-in diagnostic recorder (local disk save on `127.0.0.1`, zero-error browser download on static hosts). Sibling `crux`, `chalk-sandbox`, and `cruxscope-legacy` projects remain separate.

### Milestone 1–8 engineering & art-direction upgrades

1. **Low-latency camera pipeline, Holistic 2D fix & seated framing (`Camera.ts`, `inference.worker.ts`, `upstream.ts`, `gestures.ts`):**
   - Schedules frame capture via `video.requestVideoFrameCallback` (with `requestAnimationFrame` fallback) and downscales `> 640 px` video frames to aspect-preserving `640×360` bitmaps (`resizeQuality: "low"`), cutting `1280×720` pixel copy/upload `4×`.
   - Unwraps `@mediapipe/tasks-vision@0.10.32` 2D per-person arrays (`poseLandmarks?.[0]`, `leftHandLandmarks?.[0]`, `rightHandLandmarks?.[0]`) in `normalizeHolisticResult()`.
   - Lowers `HandLandmarker` confidence thresholds to `0.45 / 0.45 / 0.45` and adds a `140 ms` post-ready grip/orientation continuity buffer across transient closed-fist landmark dropouts (`quality === true`, cleared immediately on `"release"`, `!quality`, `recenter()`, or `stop()`).
   - Fixes metric 3D `world` mirroring (`x: -p.x`), gates `scores.fist > 0.72` so calibrated/geometric `crimp`/`pinch` shapes are never clobbered into `"jug"`, and rescues foreshortened splayed open-hand releases (`scores.open > 0.78 && openness > 0.58`).
   - Widens seated `resetSafe` to `x ∈ (0.11, 0.89), y ∈ (0.16, 0.90)` (fingertips `0.025..0.975`), tightens `frameEdge` to `x < 0.045 / > 0.955, y < 0.06 / > 0.965` (`>= 0.065` hysteresis), and resets dropped free-hand offsets (`!held[side]`) on `recenter()` to chest-ready `v(±0.18, 0.42)`.
2. **Planted-hand physics, anti-snag & dyno release window (`Simulation.ts`, `AnchorRig.ts`, `HandAnchors.ts`):**
   - Computes hold-scaled `capacities()` immediately inside `attach()` and re-syncs `AnchorRig.updateSupport()` when substep `0` acquires a hold.
   - Blocks accidental upward-sweep re-catches on lower `start`/`visited` holds unless `dist(aim, center) <= 0.85 * radius`, and smoothly weights `inverseHandCorrection` toward the upper pulling hand (`up to 0.78 / 0.22`) on vertical splits (`|Δy| > 0.20 m`).
   - Adds bounded spring-damped postural torso sway (`±0.20 rad`, `0` at rest/rebase, zero inversions) with damped leg pendulum (`angularDamping = 1.4`), extends `ReleaseVelocity` to a `0.18 s` peak-preserving pull window (`maxSpeed = 4.2 m/s`), and exposes `sim.strain(side)` (`0..1`) and `sim.assisted`.
3. **Visual craft, procedural Web Audio, Assisted mode & Personal Best Ghosts (`FollowCamera.ts`, `Renderer.ts`, `Audio.ts`, `main.ts`, `style.css`):**
   - Adds bounded velocity lookahead in `FollowCamera`, visited chalk wear, `L`/`R` match arcs, Undercling/sidepull double-chevrons, climber drop shadow, crossed-arm front/back depth sorting, gaze tracking, and amber/coral strain warning arcs + HUD `· straining!` cues.
   - Synthesizes zero-asset procedural Web Audio (`catch` triangle thud + rock tap + `"Dyno"`/`"Clean"` fifth ping, `release` brush, `slip` chalk scrape, `launch` air rush, `checkpoint` tick, `fall` glide, `finish` `C5–G5–C6` chime) routed to both `destination` and `capture`.
   - Ships **Assisted climb mode** (badged `· ASSISTED`, stored under separate save keys), **Personal Best Ghost** recording/interpolation (`crux-motion:ghost:<route>`), responsive `1280×720` / `1024×640` layout, and inline SVG favicons.
4. **Batched 2D Canvas, zero-JSON 120 Hz hot path, live intro showcase & GitHub Pages deployment (`Renderer.ts`, `Simulation.ts`, `Recorder.ts`, `main.ts`, `.github/workflows/pages.yml`, `validate-web.mjs`):**
   - Caches wall `bgGradient` and spotlight washes, batches all panel seam lines into one `stroke()`, and viewport-culls + batches the procedural bolt grid into one `beginPath()` + `fill()` (eliminating 600+ per-frame draw calls).
   - Eliminates `JSON.stringify` / `structuredClone` from `Simulation.setInput()` and `Simulation.step()` via structural `armEqual`, `inputsEqual`, and `cloneInputs` helpers with 100% identical replay capture.
   - Adds an autonomous landing physics showcase (`motion-01`, `motion-07`, `motion-10`, `motion-12`, muted, zero save/ghost writes, paused under `prefers-reduced-motion` or hidden tabs), `?route=` deep-linking, static-host recorder download fallback, unified GitHub Pages CI/CD (`pages.yml`), and personal website portfolio integration (`https://superjay0208.github.io/`).
5. **Simultaneous Two-Hand Dynos, Swing & Push-Up Momentum, Apex Deadpoints & Impact Frames (`Simulation.ts`, `AnchorRig.ts`, `Renderer.ts`, `Audio.ts`, `main.ts`, `style.css`):**
   - Adds a zero-allocation `17`-tick (`~140 ms`) rolling TypedArray momentum window scoring dual-supported **Push-Up** (`vy / 0.48`) and **Swing** (`|vx| / 0.50`, converting lateral pendulum upswing into an upward-and-across ballistic vector capped at `4.2 m/s`, decaying cleanly to `0` when stationary) plus a `<= 16`-tick (`~133 ms`) simultaneous intentional two-hand release gate (`dynoLaunch`, pure `-9.81 m/s²` airborne flight).
   - Adds **Apex Deadpoint catches** (`|vy| < 0.95 m/s` on dyno catches: `35%` lower catch shock, `apexCatchCount`, `APEX DYNO!` callout), passive leg-whip + bounded postural recoil (`AnchorRig.onCatch`), and active chalk rest flecks (`resting(side)`).
   - Renders on-wall **Momentum Charge Arcs** (`DYNO READY!`) and batched **7-dot Ballistic Launch Arc previews** (`t = 0.05..0.35 s`), Spider-Verse/Celeste **Impact Frames** (`45–70 ms` radial contrast flash, single-batch double shockwave rings + 12 radial speed lines, hold/silhouette rim highlights, directional chalk burst cones, deduplicated two-hand catch callouts), and **Micro Hit-Stop** (`24 ms` in live Camera mode, `42 ms` in Practice/Review, `0 ms` under `prefers-reduced-motion`), paired with punchy `115 → 390 Hz` launch whooshes and `92 → 34 Hz` sub-bass + `D5–A5–F#6` apex catch audio.
   - Adds Practice simultaneous two-hand release (`KeyV` + `#release-both`), symmetrical airborne dual-hand pointer aim (`±0.085 m`) + `KeyG`/pointer dual-hand arming, velocity-building `W`/`Space` (`0.16 m`) & `A`/`D` (`±0.42 m`) sweeps, live `#motion-feedback` dyno charge HUD (`SWING` / `PUSH UP`), and `window.cruxMotion` dyno diagnostics.
6. **Milestone 8 Overhaul — 3 High-Margin Grips, Warm Topo Art & Anatomical Climber, Dual Stamina, 12 Open Boulders & Pure Match-Top Rule (`types.ts`, `gestures.ts`, `upstream.ts`, `Camera.ts`, `levels.ts`, `Simulation.ts`, `Renderer.ts`, `main.ts`, `style.css`, `public/fonts/*`):**
   - **Complete `sloper` removal & 4-class gesture margin (`>= 0.25`):** focuses recognition on `jug` (closed fist), `crimp` (arched claw hook), `pinch` (thumb-index beak/O-pinch), and `release` (5-finger spread), enforcing strict `grip === hold` matching in Standard mode, stripping legacy `prototypes.sloper` from `localStorage`, guarding rolled fists (`compact < 1.24`) against `pinch` misclassification (`<= 0.08`), and exposing smooth `0..1` `camera.classScores` driving `#gesture-bars` in Camera mode and `Grip lab`.
   - **Warm limestone/terracotta bouldering topo UI & self-hosted fonts:** ships OFL `Fredoka-Variable.ttf`, `BebasNeue-Regular.ttf`, and `BarlowCondensed-{Regular,ExtraBold}.ttf` (`0` external requests, `0` Arial fallback), warm `--bg: #181512` / `--card: #231f1b` surfaces, physical bottom-bevel buttons, and an interactive 12-boulder landing grid (`#front-boulder-grid` with all 12 problems unlocked).
   - **Anatomical 2D climber & 3D sculpted holds (`Renderer.ts`):** replaces stick limbs with `drawSculptedLimb` tapered polygons (2-segment IK thighs/calves, downturned climbing shoes, terracotta `#d96b43` raglan top, swaying chalk bag, fluttering `#eb9c28` headband, expressive gaze/mouth, 4 sculpted hand poses + `L`/`R` wrist tape) over low-poly architectural wall volumes and sculpted emerald `#2fb370` Jug buckets, ochre `#eb9c28` Crimp rails, vermilion `#e55938` Pinch tufas, and sandstone `#f5ede0` TOP volumes.

## Human acceptance and current limits

Counterfactual replays feed fixed historical landmarks into updated controls without live visual feedback, and pilot/Playwright checks use synthetic or blank-frame inputs. Fresh live human webcam sessions on this build are still required to confirm real-world comfort, end-to-end `640×360` webcam frame-age improvement, gesture naturalness, dyno feel, and human route completions across the 12-route campaign. A local route editor remains future scope. See [validation/REPORT.md](validation/REPORT.md).
